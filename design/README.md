# Hikyaku synthetic desktop prototype

**Mockup only** — not the WPF client. No network calls, credentials, shell, Git, or filesystem operations.

## Open

Open `index.html` in a local browser (double-click or `Start-Process design\index.html`).

## What to click

- Primary nav: Chats, Bots, Inbox, Projects, Settings  
- **Advanced** toggle in the top bar (and Settings)  
- Needs-you badge → approval sheet  
- Projects → grant folder → Files / Changes / Terminal drawer  
- Changes: Save checkpoint vs Push (separate)  
- Scenario chips in the demo rail (right of narrow layouts: bottom rail)

All outcomes are labelled **Simulated**.
