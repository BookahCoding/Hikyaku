# App-wide UI and UX review — 0.7.7

The review covered every main screen using synthetic data, with desktop and 780px-wide captures. No live gateway was contacted.

| Area | Changes |
|---|---|
| Inbox | Counted status filters, available-answer search, custom empty folders, clear creation/move actions, readable cards and specific empty states |
| Settings | Light/Dark/System before gallery, wheel scrolling over tiles and blank space, nested boundary handoff |
| Themes and shared controls | Neutral off-white/black main surfaces, two distinct accents, visible full-track scrollbars, selected tabs and checked indicators, bounded vertical lists |
| Scheduled and Capabilities | Readable cards, labelled state and timing, grouped actions and wrapping descriptions |
| Projects | Guided folder workflow, file browsing, optional sharing/terminal controls, separate checkpoint/publish/worktree sections |
| Bots and Rooms | Keyboard Open actions, wrapping toolbars, full-width room title, bounded approvals |
| Artifacts and Journey | Visible search/filter selection, wrapping actions, readable cards and bounded previews |
| Insights | Visible selected period, accessible daily values in an optional bounded disclosure |
| Needs you | Clear empty state, wrapped requests, labelled answer fields |
| Voice, terminal and editor dialogs | Wrapping controls, bounded explanations and usable output area |

Independent review caught and corrected lost concurrent folder edits, collapsed results after filtering, unbounded list widths, terminal help crowding, excessive Insights detail and room-title truncation. Regression tests exercised the broken behavior before fixes.

Search uses result text already available locally and does not fetch all historical answers. Folder organization is local to this PC; it does not alter gateway jobs. Existing profile filtering, action confirmations and Simple/Advanced rules remain in effect.

Final validation is recorded in the release handoff after the full build and fresh published-app acceptance run.
