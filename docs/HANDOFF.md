## Stage 15a — voice capability split
- **Defect (reproduced):** the status probe on `api/audio/voice-live/status` gated dictation. `available:false`, a legacy body, 404, 429/5xx or a network error all became `Unsupported`, so STT was disabled whenever GPT-Live was merely unavailable. Android (`AudioApi.kt` @ 5f00986b) defines `available` as "GPT-Live can start" and treats a failing status call as chained mode.
- **Fix:** `AudioApi.ProbeAsync` returns `AudioProbe(Dictation, VoiceLive)`. Only 401/403 (auth covers all of `/api/audio`) gate dictation (`SetupRequired`). A 404 from the real transcribe route flips the controller to `Unsupported` for that scope only (late results from a previous scope are discarded). Bounded status reads and fail-closed auth are unchanged.
