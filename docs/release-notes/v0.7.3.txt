Hikyaku 0.7.3 - ordinary profile chats, local models, and automatic releases

- Opening Shisha, or another profile that only has a display name, from the roster starts an ordinary chat. A profile is a bot only when Bot Mode was set up for it. The existing chat titled "Bot Chat" is left as it is.
- The model menu keeps local and custom providers that do not use a cloud API key (llama.cpp, Ollama, LM Studio, and a custom endpoint), including when they have no price. A cloud provider that still needs a key stays hidden.
- Signed releases are built automatically.

Update from Settings > Updates > Check for updates. Your settings and sign-in are kept.
For a first installation, use Hikyaku-Setup-0.7.3.exe.
